INSTAKROSS — комплект проекта

index.html — витрина магазина.
admin.html — административная панель.
backend/ — API, схема базы и настройки окружения.
dist/ — production-сборка Worker.
.openai/hosting.json — конфигурация Sites.

Важно: пароли, API-ключи и секреты в комплект не входят. Файл backend/.env.example содержит только имена необходимых переменных.
